##  Comandos básicos - Git Bash

- `mkdir nome_da_pasta` → criar pasta

- `clear` → limpar tela

- `git config --list` → ver configurações

- `git config --global user.name "seu nome"` → adicionar nome

- `git config --global user.email "seu email"` → adicionar email


##  Comandos básicos - GitHub

- `cd nome_da_pasta` → entrar na pasta

- `git clone link_do_repositório` → baixar projeto
 
- `git status` → ver alterações

- `git add .` → adicionar arquivos

- `git commit -m "descrição"` → salvar alterações

- `git push` → enviar para o GitHub

- `git pull` → atualizar projeto  > *Para alterações manuais*
